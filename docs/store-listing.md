## 简短描述（132 字符内）

开源多引擎网页翻译。DeepSeek/Claude/OpenAI/Google/DeepL 自由切换，API Key 存本地，数据不经过第三方服务器。

## 详细描述

**TransFlow** 是一款开源的浏览器翻译插件，支持 DeepSeek、Claude、OpenAI、Google Translate、DeepL 等多个翻译引擎自由切换。

### 核心特性

- 🔒 **隐私优先** — API Key 仅存储在浏览器本地，翻译请求直接从你的浏览器发往引擎 API，不经过任何中间服务器
- 🤖 **多引擎支持** — DeepSeek、Claude、OpenAI、Google Translate、DeepL，自由选择主力引擎和备用引擎，调用失败自动切换
- 📖 **行间双语对照** — 译文直接插入原文下方，阅读流畅，支持一键还原
- 🔍 **划词翻译** — 选中文字 → 右键 →「翻译选中文字」，译文气泡即时显示，可复制、朗读
- 💾 **智能缓存** — 全文 hash 匹配，二次翻译同一页面几乎零延迟，节省 API 用量
- 🌐 **SPA 页面支持** — 自动监听动态内容变化，新出现的文字即时翻译
- 🆓 **完全开源免费** — MIT 许可证，无会员、无订阅、无广告

### 推荐配置

推荐使用 **DeepSeek API** 作为主力引擎（约 ¥2/百万 token，免费注册获取），配合 Google Translate 作为免费备用引擎。

### 隐私声明

TransFlow **不会**上传你的 API Key、翻译内容或浏览记录到任何第三方服务器。所有数据均存储在你的浏览器本地。你能随时通过浏览器开发者工具验证网络请求的发送目标。
